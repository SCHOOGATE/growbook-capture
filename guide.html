思いついたその場で送れる

写真を撮る・アルバムから何枚も選ぶ・声で話す。スマホのボタンひとつで送れます。

🔒

送り先は自分のドライブだけ

材料はあなた自身の Google ドライブ「GrowBookForge材料」に入ります。合言葉を知っている自分だけが送れます。

🗂

本ごと・日付ごとに自動で整理

アプリから「＋ 新しい本を作る」でフォルダを作り、送ったものは「本／日付」に分かれて入ります。

録った声は10分ごとに書き起こされ、日付ごとの「材料メモ」にまとまります（Gemini の API キーが必要・少額の費用）。

「左に写真・右に日記」などの見開きの型を選ぶか、チャットで相談しながら写真集にする仕組みを作っています。

今日はこの中の「スマホのアプリを自分用に入れる」ところまで進めます（パソコンとスマホで約15分）。

導入の手順（今日やること）

用意するもの：パソコン（Chrome）／スマホ／自分の Google アカウント。パソコンとスマホは同じ Google アカウントでなくてもかまいません。

  1. パソコンで Apps Script を開く

    パソコンの Chrome で自分の Google アカウントにログインした状態で、script.new を開きます。新しい「無題のプロジェクト」ができます。
    • 左上の「無題のプロジェクト」を押して、名前を GrowBook Capture にします

  2. アプリの中身（コード）を貼る

    下の「コードをコピー」を押します → エディタの中身を全部消して（Ctrl+A → Delete）、貼り付けます（Ctrl+V）→ 保存（Ctrl+S）。 
    読み込み中…

  3. 「setup」を実行して、合言葉をもらう

    エディタの上にある関数の選択（「doGet」などと出ている欄）で setup を選び、▷ 実行 を押します。
    • 「承認が必要です」→ 権限を確認 → 自分のアカウントを選ぶ
    • 「このアプリは Google で確認されていません」→ 詳細（Advanced）→ GrowBook Capture（安全ではないページ）に移動（Go to … (unsafe)）
    • 許可の画面では 「すべて選択」にチェック → 続行（Allow）
    • 下の「実行ログ」に 合言葉: …… と出ます。英数字の部分をコピーしておきます
    「確認されていません」は、自分で作ったアプリなら必ず出る表示です。作ったのも使うのも自分自身なので、そのまま進めて大丈夫です。

  4. ウェブアプリとして公開する

    右上の デプロイ → 新しいデプロイ → 左の ⚙ で ウェブアプリ を選びます。
    • 次のユーザーとして実行：自分
    • アクセスできるユーザー：全員
    • デプロイ を押す → 出てきた 「ウェブアプリ」のURL（https://script.google.com/macros/s/…/exec）をコピー
    「全員」にしないとスマホから送れません。送るには合言葉が要るので、URLを知っていても他の人は送れません。

  5. 自分専用リンクを作る（このページで）

    コピーした2つをここに貼って、ボタンを押します。このパソコンの中だけで作るので、どこにも送られません。

    スマホのカメラでこのQRコードを読んでください

  6. スマホで開いて、ホーム画面に置く

    QRコードから開いたら、Android は Chrome、iPhone は Safari で開きます（LINE などの中で開いた場合は「ブラウザで開く」）。
    • Android：右上の「︙」→ ホーム画面に追加
    • iPhone：下の共有ボタン → ホーム画面に追加
    • 青いアイコンの GrowBook Capture がホーム画面に並びます。一度開けば、スマホが設定を覚えます

  7. 本を作って、1枚送ってみる

    アプリで ＋ 新しい本を作る → 本の名前を入れて 作る → 「送り先」がその本になっているのを確かめて、📷 写真を撮る か 写真から選ぶ。
    • 「保存しました」と出たら完了です。📂 保存先を開く で自分のドライブに入ったのを確かめられます

声を文字にする（任意・あとからでOK）

  1. Google AI Studio で API キーを作る（無料枠は入力が改善に使われることがあるため、課金の設定をおすすめします）
  2. Apps Script の左の ⚙ プロジェクトの設定 → 一番下の スクリプト プロパティを追加 → プロパティ GEMINI_API_KEY／値にキー → 保存
  3. 関数で setupTrigger を選んで ▷ 実行（許可は「すべて選択」）。以後10分ごとに、新しい声が文字になります

キーは人に見せない・チャットに貼らないでください。

大事なこと

  • 合言葉・自分専用リンク・QRコードは人に渡さない（渡すと、その人もあなたのドライブに送れてしまいます）
  • 材料はあなたのドライブにだけ入ります。消したいときはドライブから消せます
  • うまくいかないときは、出た画面（赤い字など）をそのまま見せてください
